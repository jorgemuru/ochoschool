Monitorización con Zabbix

Zabbix 7.0 sobre Ubuntu 24.04 y PostgreSQL centraliza el estado de servidores y red.

Objetivos de monitoreo

ActivoMétodoIndicadores
MikroTikSNMP UDP/161Disponibilidad, interfaces, tráfico, CPU
Ubuntu/WildFlyAgente + HTTPCPU, memoria, disco, proceso y endpoint
Windows ServerAgenteServicios AD/DNS/DHCP, recursos
OracleAgente/scriptsListener, puerto y espacio
Website/APIWeb scenarioCódigo HTTP, tiempo de respuesta

Validación SNMP

snmpwalk -v2c -c COMUNIDAD_SEGURA 192.168.80.1 1.3.6.1.2.1.1
sudo tcpdump -ni any udp port 161

Alertas recomendadas

  • Host inaccesible.
  • Interfaz VPN caída.
  • Disco > 80 %.
  • WildFly detenido.
  • Puerto 1521 sin respuesta.
  • Endpoint de login con error o latencia alta.
Seguridad SNMP

Limite la comunidad al host Zabbix (192.168.80.20), use una cadena no predeterminada y considere SNMPv3 en producción.
