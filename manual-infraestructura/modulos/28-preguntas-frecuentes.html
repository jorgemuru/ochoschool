Preguntas frecuentes

¿Por qué el Website usa localhost para la API?

Cuando ambos WAR se ejecutan en el mismo WildFly, localhost evita atravesar la red. Para acceso desde otro servidor se utiliza la IP o FQDN del host.

¿Por qué Rivera recibe DHCP desde Paysandú?

El relay convierte el broadcast DHCP en tráfico unicast hacia el servidor central, evitando instalar un servidor por sede.

¿Por qué no pueden los usuarios acceder a Oracle?

Solo la capa de aplicación necesita conectarse a la base. Bloquear el acceso directo reduce exposición y fuerza el uso de reglas de negocio.

¿Qué significa un archivo .failed?

El scanner intentó desplegar el artefacto y WildFly encontró un error. Debe revisarse el contenido del marker y server.log.

¿Se puede publicar el standalone.xml original?

No. Contiene credenciales, nombres, direcciones y detalles operativos. Solo debe publicarse una versión sanitizada.

¿Qué ocurre si DNS falla?

Puede fallar la unión al dominio, LDAP, Oracle por nombre y otras dependencias. DNS es una prioridad de diagnóstico.

¿Cómo sé qué GPO se aplicó?

Use gpresult /r, un informe HTML o rsop.msc.

¿Por qué usar Zabbix?

Permite detectar fallos antes del reporte de usuarios y correlacionar red, servidores y aplicaciones.
